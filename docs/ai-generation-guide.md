# AI로 리드마그넷 폼 HTML 만들기 (입력 계약)

이 시스템은 AI가 만든 **단일 HTML 파일**을 운영자가 등록하는 것으로 시작한다. 실제 AI 호출은 시스템 밖에서 일어난다(과제 범위). 아래는 "어떤 HTML을 만들어야 그대로 동작하는가"에 대한 계약과, 운영자가 AI에 붙여넣을 프롬프트다.

## 1. 시스템이 받는 HTML의 조건

| 조건 | 이유 |
|---|---|
| 확장자 `.html`, 512KB 이하 | 업로드 검증 규칙 |
| `<form>` 태그 1개 이상 | 제출을 가로채 CRM에 저장하려면 폼이 있어야 한다 |
| 입력 요소마다 `name` 속성 | `name`이 CRM 명단의 필드 키가 된다. 없으면 값이 저장되지 않는다 |
| 스타일은 인라인 `<style>` | sandbox iframe 안에서 렌더되며 CSP가 외부 스크립트를 막는다. 외부 CSS·폰트는 https면 허용 |
| `action`·`method`·자체 fetch 불필요 | 서버가 주입하는 스크립트가 submit을 가로채 JSON으로 보낸다. 있어도 무시된다 |
| 관리자·인증 관련 내용 없음 | 등록 HTML은 관리자 API에 접근할 수 없다(격리 3겹) |

제출 성공 시 폼은 `<p data-lead-success>성공 메시지</p>`로 교체된다. 실패 시 폼 위에 `<p data-lead-error>`가 붙는다. 이 두 요소의 스타일을 미리 넣어 두면 좋다.

## 2. 프롬프트 템플릿 (운영자가 AI에 붙여넣는 것)

```
다음 조건으로 리드마그넷 신청 페이지를 완전한 HTML 파일 하나로 만들어 줘.

[캠페인] {캠페인 이름과 한 줄 설명}
[제공물] {무료 체크리스트 / 뉴스레터 / 전자책 등}
[수집 항목] 이름(name, 필수), 이메일(email, 필수), {추가 항목: 예 관심 분야 select}

규칙:
- <!doctype html>부터 </html>까지 파일 하나. 외부 JS 없음. CSS는 <style> 안에.
- <form> 하나. 모든 input/select/textarea에 name 속성. 제출 버튼은 <button type="submit">.
- action, method, onsubmit, fetch는 쓰지 마. 제출은 시스템이 처리해.
- 폼 아래에 개인정보 수집 동의 체크박스(name="consent", required).
- 제출 성공 시 폼이 <p data-lead-success>로 바뀌니 그 클래스의 스타일도 넣어 줘. 오류는 <p data-lead-error>.
- 모바일 우선, 한국어.
```

## 3. 샘플

`samples/` 폴더에 이 프롬프트로 생성한 HTML이 있다. 각 파일 머리의 주석에 생성 도구와 사용한 프롬프트 값이 적혀 있다. 관리자 화면 → 템플릿 → 이 파일을 등록하면 바로 캠페인·폼·링크를 만들어 방문과 제출을 시연할 수 있다.

## 4. 나중에 실제 AI를 붙인다면 (ADR 0012)

생성 단계는 템플릿 등록 **앞**에 붙는 별도 모듈이다. 생성 결과를 `TemplatesService.create(file, name)`과 같은 입구로 넣으므로 격리·제출 계약·집계는 바뀌지 않는다. API 키는 `.env`의 `AI_API_KEY`로만 들어오고 `loadEnv()`가 읽는다. 저장소에는 키가 들어가지 않는다(커밋 가드가 차단).
